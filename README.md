## 🌟 v3.0.0 核心更新特性 (Features & Highlights)

### 1. 🎨 全新 NovaDesk 现代生产力工作台 (WorkBuddy 级像素复刻)
- **双态无缝交互切换**：空态「悬浮居中 Hero 提问卡片」与对话态「固底精致 DockCard 输入框」流畅转换。
- **侧边栏「独立双滑动窗口」**：任务专区与空间专区各自分配独立精致的 4px 极细深灰滚动条，两区域独立滑动、互不遮挡，彻底消除空间挤压与留白问题。
- **任务置顶与层级分类**：支持任务置顶、会话重命名、归档与搜索筛选，置顶任务与常规任务自动呈现层级分隔。
- **纯净 Markdown 优雅排版**：高对比度冷白文字、代码高亮、支持一键复制、重新提问、语音朗读、点赞点踩与真实 Token 消耗统计。
- **丝滑淡入过渡动画**：基于 Qt 属性动画（`QPropertyAnimation`），点击桌宠唤醒工作台时享受平滑透明度淡入浮现。

### 2. 🌸 正版 Live2D 桃濑日和 (Hiyori) 灵动陪伴
- **原生动作与视线追踪**：保留官方原汁原味 Live2D 面部与身体动态，支持全局鼠标视线实时跟随与呼吸感。
- **全局键盘同步敲击**：打字时角色桌面联动敲击键盘，提供沉浸式桌面伴侣体验。
- **一键快捷唤醒**：鼠标左键**双击人物**即可瞬间呼出 AI 工作台。

### 3. 🤖 强劲双轨 AI 引擎 (Local + Cloud) 与零幻觉真实路由
- **本地 Ollama 真实探测**：自动扫描本地已下载安装的真实模型（如 `deepseek-r1:14b`、`qwen2.5:7b` 等），测试连接时严格校验本地是否已拉取该模型，拒绝任何虚假状态。
- **Ollama 长上下文 `/api/chat` 原生流式**：采用原生 chat 接口携带多轮历史对话，打通真实多轮记忆。
- **外部云端 API 完整对接**：支持无缝接入 DeepSeek 官方 API、OpenAI 兼容接口、硅基流动等外部模型，支持自定义 Base URL、API Key（密码遮罩）与模型名称。
- **拆除一切硬编码假回复**：所有问答与工具调用 100% 真实执行，网络异常或离线时诚实诊断并报告原因。

### 4. 🧩 40+ 真实生产力技能与专家生态 (Skills & Agents)
- **专家大厅一键召唤**：内置 Python 开发专家、PPT 生成大师、小红书运营操盘手、文案策划专家等多角色模版。
- **原生实用工具生态**：
  - 🗺️ **高德地图生活导航**：真实路线规划与起点终点导航；
  - 🚄 **12306 车票查询**：实时列车时刻与余票检索；
  - 📦 **快递 100 物流追踪**：快递单号实时轨迹追踪；
  - 🕷️ **Firecrawl 网页爬取 & 联网搜索**：实时头条要闻汇编与 DuckDuckGo 网页检索；
  - 📄 **文档大师与 PPT 工具**：支持 Word 文档解析、PDF 读取与 PPT 大纲生成；
  - 💻 **计算机控制与本地代码执行**：安全沙箱下的 Python 脚本解释器与屏幕截图感知。
- **「我安装的」专属插件管理**：支持插件开关实时控制、分类过滤与搜索。

### 5. 📁 多工作空间与本地文件系统深度联动
- **本地真实工作空间关联**：支持关联本地多个工作文件夹，在侧边栏一键直接打开系统文件资源管理器。
- **会话持久化归档**：支持将对话历史一键导出为标准的 `.md` Markdown 文件并保存到当前工作空间。
- **本地文件 `@引用` 解析**：支持在输入框点击 `+` 快速加载本地代码或文档文件进行深度提问与分析。

### 6. ⚡ 自动化任务与智能调度流 (PetScheduler)
- **定时与周期自动化任务**：支持设置定时提醒、番茄钟工作法与周期性后台任务。
- **全局声音与语音播报控制**：内置基于 Edge-TTS 的高拟真语音合成，支持全局一键开启/静音所有互动音效。

### 7. 🔒 安全沙箱与高可靠 SQLite 记忆中枢
- **会话严格隔离**：按会话 ID 隔离上下文历史，多会话切换绝不串台。
- **SQLite 自动资源管理**：使用连接生命周期上下文管理器，在 WAL 预写日志模式下保证高并发读写并杜绝连接句柄泄漏。

## 🚀 快速开始

### 1. 安装依赖
确保本地已安装 Python 3.10+，执行以下命令安装依赖：
```bash
pip install -r requirements.txt
```

### 2. 启动本地 Ollama (可选，若使用本地模型)
确保 Ollama 服务处于运行状态，并已拉取所需模型：
```bash
ollama run deepseek-r1:14b
```

### 3. 一键启动
在项目根目录下双击运行：
```bash
start.bat
```
或在终端执行：
```bash
python main.py
```

## 🎮 使用指南

| 操作 | 响应效果 |
| :--- | :--- |
| **双击人物** | 瞬间平滑淡入唤醒 NovaDesk v3.0 全功能工作台 |
| **右键人物** | 弹出快捷菜单（💬 开启对话 / 📜 历史会话 / ⚙️ 设置与模型 / 👁️ 隐藏到托盘 / ❌ 退出） |
| **拖拽人物** | 鼠标左键按住人物身体即可在桌面上随意拖动摆放 |
| **侧边栏滑动** | 上方任务专区与下方空间专区各自独立滑动，互不干扰遮挡 |
| **输入框附件** | 点击 `+` 号一键引用并分析本地文档与代码文件 |
| **全局声音控制** | 侧边栏底部一键开启或静音全部互动音效与语音提醒 |
