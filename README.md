# 🌸 Desktop AI Assistant v2.0.0 (桌面 AI 智能助理)

> 基于 **PyQt5 + Live2D 官方官方桃濑日和 (Hiyori) + 本地 Ollama (DeepSeek-R1 / Qwen) & 外部云端大模型** 的现代沉浸式桌面 AI 陪伴助理与对话中枢。

## 📢 v2.0.0 版本发布声明 (Release v2.0.0)

我们非常高兴地正式发布 **Desktop AI Assistant v2.0.0**！本次版本经历系统级重构，带来了全新的 Live2D 正版角色渲染、极速本地模型扫描、外部云端 API 对接、多会话历史中枢与 Windows 原生四角精准交互体验。

## 🌟 v2.0.0 核心更新特性 (Features & Highlights)

### 1. 🌸 正版 Live2D 桃濑日和 (Hiyori) 精致小巧版
- **原生动作与视线追踪**：保留官方原汁原味 Live2D 面部与身体动态，支持全局鼠标视线实时跟随与呼吸感。
- **全局键盘同步敲击**：打字时角色桌面联动敲击键盘，提供沉浸式桌面伴侣体验。
- **一键快捷唤醒**：鼠标左键**双击人物**即可瞬间呼出 AI 对话中枢。

### 2. 🤖 强劲双轨 AI 对话中枢 (Local + Cloud)
- **本地 Ollama 实时自动扫描**：启动自动扫描本地已下载安装的真实模型（如 `deepseek-r1:14b`、`qwen2.5:7b` 等），拒绝假数据，支持一键实时刷新。
- **外部云端 API 完整对接**：支持无缝接入 DeepSeek 官方 API、OpenAI 兼容接口、硅基流动等外部模型，支持自定义 Base URL、API Key（密码遮罩）与模型名称。
- **极速流式响应**：基于异步事件循环的流式打字机输出，思考与回复过程行云流水。
- **本地工具与文件读写**：内置工具调用引擎，支持通过自然语言对本地文件进行真实创建、写入与读取。

### 3. 📜 多会话历史归类与记忆管理
- **多会话分类与创建**：支持创建多个独立主题会话，根据首轮提问**智能提炼并生成会话标题**。
- **会话无缝回溯**：随时点击历史列表切换上下文，完整还原过往聊天记录。
- **内存与持久化同步清理**：支持单条会话删除与一键清空，同步抹除 SQLite 数据库与 AI 运行内存中的上下文。

### 4. ⚙️ 内置控制面板与极致视觉体验
- **对话与设置深度一体化**：设置面板直接内置于对话中枢（`⚙️ 设置`），标签页切换 **0 延迟、0 闪烁**。
- **高雅实体深色主题**：告别半透明模糊与透光重叠，所有字体、下拉菜单（`QComboBox`）黑白分明、清晰利落。
- **Windows 原生四角精准缩放**：采用底层 `WM_NCHITTEST` / `SC_SIZE` 机制，**仅四个角落边缘支持拖拽缩放**，彻底杜绝平直边缘误触与输入框光标冲突。
- **标准任务栏状态栏常驻**：点击最小化（`—`）窗口标准收缩并**常驻在 Windows 底部任务栏**，托盘与任务栏双重保障。

│   ├── chat_window.py         # AI 智能对话中枢 (多会话/设置/原生四角缩放)
│   ├── desktop_pet.py         # Live2D 桌面宠物悬浮窗与双击/右键交互

## 🚀 快速开始

### 1. 安装依赖
确保本地已安装 Python 3.10+，执行以下命令安装依赖：
```bash
pip install -r requirements.txt
```

### 2. 启动本地 Ollama (可选，若使用本地模型)
确保 Ollama 服务处于运行状态，并已拉取所需模型：
```bash
ollama run deepseek-r1:14b
```

### 3. 一键启动
在项目根目录下双击运行：
```bash
start.bat
```
或在终端执行：
```bash
python main.py
```

## 🎮 使用指南

| 操作 | 响应效果 |
| :--- | :--- |
| **双击人物** | 瞬间唤醒打开 AI 智能对话中枢 |
| **右键人物** | 弹出快捷菜单（💬 开启对话 / 📜 历史会话 / ⚙️ 设置与模型 / 👁️ 隐藏到托盘 / ❌ 退出） |
| **拖拽人物** | 鼠标左键按住人物身体即可在桌面上随意拖动摆放 |
| **中枢四角缩放** | 将鼠标移至对话中枢的**左上、右上、左下、右下四个角落**即可自由拉伸窗口 |
| **窗口最小化** | 点击右上角 `—` 最小化至 Windows 底部任务栏，点击任务栏小桃图标即可恢复 |
| **模型与服务切换** | 点击右上角 `⚙️ 设置` 即可自由切换本地 Ollama 或外部云端 API (DeepSeek/OpenAI) |
