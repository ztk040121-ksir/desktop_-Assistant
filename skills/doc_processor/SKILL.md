# Document Processor Skill (智能文档处理技能)

## 技能概述
提供对 Word (.docx) 和 PDF (.pdf) 文档的自动化处理能力，包括读取文档全文、提取核心结构、跨段落/表格查找替换、以及生成带层级样式的总结报告。
