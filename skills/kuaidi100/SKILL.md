# 快递100 智能物流查询 Skill (Kuaidi100 Logistics Skill)

## 技能概述
基于快递100官方 MCP 与开放 API，提供全球 3000+ 家快递物流公司单号轨迹追踪、智能运力匹配与跨城寄件运费时效预估。

## 核心功能
1. **单号轨迹追踪**：自动识别快递公司编码，输出包含时间节点、派件员联系电话与当前物流节点的完整轨迹。
2. **运费与时效预估**：输入寄件地、目的地与包裹重量，比对各主流快递公司的预估费用与送达耗时。

## 触发意图示例
- "帮我查一下顺丰单号 SF1234567890 现在的物流位置"
- "从杭州寄 2kg 文件到北京，哪家快递最快，大概要多少钱？"
