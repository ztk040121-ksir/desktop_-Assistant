# Markdownify 全格式文档转换 Skill (Markdownify Skill)

## 技能概述
将办公场景常见的各类非结构化/专有格式文件（Word、PDF、Excel、PPT、图片 OCR、HTML）一键转换为清晰规范的 Markdown 文本，便于知识库沉淀与大模型分析。

## 核心功能
1. **多格式文档解析**：提取段落结构、表格数据、标题层级与列表。
2. **批量文档处理**：一键转换整个文件夹下的文档。

- "把桌面上的 docx 文件转成 md 保存"
