# 视频脚本策划技能 (Video Script Creator Skill)

本技能帮助自媒体创作者、短视频编导与营销人员一键产出结构严密的专业分镜脚本。

## 适用场景
- **科技/知识口播**：高完播率 Hook、干货要点与呼吁行动；
- **产品宣传片**：画面视效设计与镜头语言编排；
- **自媒体剧情**：情节反转与冲突设计。

## 配套工具函数 (Tools)
- `generate_video_storyboard(topic, target_duration_sec, style)`: 生成完整 Markdown 工业分镜表格文件。
