# 网站开发技能 (Web Development Skill)

本技能为开发者与企业用户提供现代化的网页与前端工程化开发能力。

## 支持的开发场景与模板

1. **企业官方网站 (Enterprise Landing Page)**
   - 采用现代渐变暗黑/极简科技风，包含 Hero 头部、特性网格、解决方案、价格方案与页脚；
   - 响应式设计，完美适配 PC、平板与手机端。

2. **后台管理系统 (Admin Dashboard)**
   - 现代化侧边导航栏、顶部状态区、多维核心 KPI 统计卡片、数据表格与操作状态流转；
   - 高对比度可读性设计。

3. **个人博客与内容站点 (Blog & Knowledge Base)**
   - 优雅的排版系统、标签归类、文章卡片流与阅读模式。

4. **电商首页与展示平台 (E-Commerce Showcase)**
   - 轮播横幅、商品分类胶囊、推荐货架与购物车浮层。

## 配套工具函数 (Tools)

- `generate_web_scaffold(project_type, project_name, title, output_dir)`: 一键在工作区生成标准工程目录及 index.html、css/style.css、js/main.js 代码。
- `start_preview_server(project_path, port)`: 启动轻量本地 HTTP 预览服务器并返回浏览地址。
- `analyze_web_structure(project_path)`: 静态分析网页结构与资源。
