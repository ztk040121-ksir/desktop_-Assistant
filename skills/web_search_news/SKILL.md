# 全网热搜与聚合新闻 Skill (Web Search News Skill)

## 技能概述
实时检索全网各大主流资讯平台热榜（微博、新浪、知乎、B站、百度），并聚合提炼出结构化的实时新闻简报。

## 核心功能
1. **多源热榜聚合**：跨平台抓取最新时事政治、科技热点与财经快讯。
2. **关键词全网搜索**：针对特定事件与实体进行深度搜索。

## 触发意图示例
- "帮我看看今天科技领域有什么重大新闻"
- "播报一下现在的微博热搜榜"
